\# Flask ChatGPT AI Assistant



A simple web-based AI chatbot built using Python, Flask, HTML, CSS, JavaScript, and the OpenAI API.



The application provides a basic chat interface where users can enter a message and receive an AI-generated response.



\## Features



\- Simple web-based chat interface

\- Flask backend

\- OpenAI API integration

\- User message input

\- AI-generated responses

\- Basic error handling

\- Environment variable support for API keys



\## Technologies Used



\- Python

\- Flask

\- OpenAI API

\- HTML

\- CSS

\- JavaScript

\- python-dotenv
